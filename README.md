# 照着拍 PoseCam 官网

一个无需构建的静态官网。桌面显示全屏梦幻天空与立体手机展示，手机自动采用可滚动的竖版布局。

## 安装包

Android 版本：1.0.2。已修复相机权限配置，支持覆盖安装旧版。
APK 放在 GitHub Releases 下载区；网页的下载按钮直接指向该文件。

## 网站文件

index.html 包含全部 CSS、JavaScript、图标与展示照片。天空视频、背景图片、立体场景与字体使用外部资源。手机展示为示意排版。

## 部署

GitHub Pages 使用 main 分支根目录。也可以把 index.html 部署到任意静态托管服务。

## 权限说明

APP 不需要管理员或设备管理权限。拍照时需要普通相机权限，保存照片时按系统提示授权。APK 仅适用于 Android。
